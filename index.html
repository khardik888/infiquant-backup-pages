InfiQuant backup (rclone)

A private tool operated by Hardik Desai to transfer, retain and restore selected InfiQuant backup files in his own Google Drive using rclone.

This is an owner-operated backup utility. It is not a public cloud storage service and does not offer account registration or Google sign-in on this website.

What the tool does

The tool runs on owner-controlled computers and uses Google OAuth to access the owner's Drive. Configured rclone crypt remotes encrypt backup file contents and names before upload. Restore checks compare recovered files with the source.

Why Google Drive access is requested

Drive access lets the tool upload and download backups, inspect file metadata and manage backup files selected by the owner. Its configured full Drive scope can technically access other Drive files; operations should remain limited to the intended backup locations.
